# 🏋️ Telegram-бот: напоминалка про тренировки и шаги

Бот на Python, который помогает не забывать про тренировки и выполнять дневную норму шагов.

## Возможности

- **Тренировка через день.** Бот напоминает утром и повторно вечером, пока вы не отметите тренировку кнопкой «Сходил ✅». Следующая тренировка назначается через 2 дня после последней выполненной. Если пропустили, напоминания продолжатся на следующий день.
- **Шаги каждый день.** Утром бот напоминает про норму (10 000 шагов), а в течение дня несколько раз спрашивает, сколько вы уже прошли.
- **Умные реакции.** Ответ зависит от числа шагов *и* от времени суток: 5 000 шагов в 15:00 это «идёшь по графику», а в 21:00 уже повод выйти на прогулку.
- **Гибкий ввод.** Понимает `8500`, `8 500`, `8.5к`, `10k шагов`.
- **Статистика.** Команда `/stats` показывает шаги за 7 дней и число тренировок за 2 недели.
- Если норма уже выполнена, бот перестаёт задавать вопросы про шаги.

## Расписание (по умолчанию, Европа/Москва)

| Время | Что происходит |
| --- | --- |
| 09:00 | Утреннее сообщение про цель по шагам и (если пора) про тренировку |
| 12:00, 15:00, 18:00 | Вопрос «сколько шагов?» |
| 19:00 | Повторное напоминание о тренировке, если она ещё не отмечена |
| 21:30 | Итоговый вопрос про шаги за день |

Время и цели меняются в `bot/config.py`.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Запустить бота |
| число (например `7500`) | Записать шаги за сегодня и получить реакцию |
| `/steps` | Шаги за сегодня |
| `/workout` | Отметить тренировку вручную |
| `/stats` | Статистика |
| `/pause` и `/resume` | Выключить и включить напоминания |

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен.
2. Установите зависимости (нужен Python 3.10+):

   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` по образцу `.env.example` и вставьте токен:

   ```bash
   cp .env.example .env
   ```

4. Запустите:

   ```bash
   python -m bot.main
   ```

5. Откройте бота в Telegram и нажмите `/start`.

## Структура проекта

```
bot/
  main.py        # точка входа, настройка планировщика
  config.py      # настройки, цели и расписание
  handlers.py    # команды, кнопки, ответы пользователя
  reminders.py   # задачи по расписанию
  logic.py       # парсинг шагов, реакции, расчёт тренировок (без Telegram)
  db.py          # работа с SQLite
tests/
  test_logic.py  # тесты логики и базы данных
```
